# HR Analytics Dashboard | Power BI

## Project Overview
This project presents an interactive HR Analytics Dashboard built using Microsoft Power BI to analyze employee data and understand workforce trends and employee attrition.

## Objectives
- Track key HR metrics using KPI cards.
- Analyze employee distribution across departments.
- Examine employee attrition by department.
- Explore attrition patterns across different age groups.
- Analyze the relationship between overtime and employee attrition.

## Dashboard Features
- **Total Employees:** Displays the total number of employees.
- **Employees Left:** Shows the number of employees who left the organization.
- **Attrition Rate:** Displays the percentage of employees who left.
- **Average Age:** Shows the average age of employees.
- **Department Analysis:** Visualizes employee distribution and attrition by department.
- **Age Group Analysis:** Examines attrition across age groups.
- **Overtime Analysis:** Compares employee attrition by overtime status.

## Tools and Technologies
- Microsoft Power BI

- HR Data Analysis
